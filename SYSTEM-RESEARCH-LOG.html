[2026-10-03] injector idempotency lesson (dashboard stale as-of)

  • A regex injector whose REPLACEMENT changes the format its MATCH expects will pass silently
    forever after the first run (subn → 0, only visible in the n_meta print). Rule: injector
    regexes must match their own output (write the replacement, then re-match IT). The same run
    printed meta:0 — read the counters, they are the smoke alarm.
  • Banner-stamp pattern must be replace-not-prepend; otherwise banners accumulate per run.
  • Public site serves the dashboard at / (index.html); /outlook-dashboard.html 404s.
